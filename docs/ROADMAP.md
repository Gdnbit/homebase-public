# HomeBase 路线图

HomeBase 的方向是让用户通过桌面或微信用自然语言交办任务，通过同一套任务状态和能力接口核对结果。CLI 向具备本机操作能力的 Agent 提供可发现的接口。

## 当前维护范围

- **助理和会话**。桌面与微信复用 Pi，统一处理工具调用、授权、状态和产物。原生 Agent 入口按来源管理会话。 [助理](assistant.md) · [原生 Agent](native-agents.md)
- **能力库**。按用途发现实现，通过同一契约描述输入、授权、状态、输出和来源。用户自行配置要安装和启用的实现。 [能力发现](capability-discovery.md)
- **环境和数据**。提供运行时预检、可移植配置、密钥生命周期和部分受管配置的追溯。 [预检](runtime-preflight.md) · [密钥](secret-lifecycle.md)
- **发布和复验**。正常源码检出可以独立构建。Windows 分发按手册另行准备固定运行时。 [维护](maintenance-goal.md) · [打包](windows-packaging.md)

## 后续方向

1. 完善任务身份证据、异常恢复和跨入口结果一致性。每次改动覆盖重投、重新打开、失败和重启。
2. 为更多能力类型补齐发现、参数、权限和结果验收。第三方适配遵循其许可证和运行条件。
3. 继续改进有界读取、缓存失效和产物管理。以可复现的调用次数或耗时作为验收指标。
4. 扩充迁移和受管配置恢复的覆盖面。目标机重新核对外部工具、平台权限和依赖。

新增功能的完成状态以源码、生成契约、验证记录与正式发布为准。分层目标见 [Agent OS 设计](agent-os-final-design.md)。

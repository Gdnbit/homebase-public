# ASR 多引擎设计与参考性能

HomeBase 的语音转写设计支持按任务选择引擎和预设，也可以对同一输入做多引擎对照。具体引擎由使用者在目标机器配置。 [工作台用法](asr-workbench-integration.md)

## 选择引擎

| 需求 | 选择依据 |
| --- | --- |
| 本地处理 | 核对语言、CPU、GPU、显存、模型文件和可用磁盘。模型或驱动就绪未知时先探测 |
| 快速草稿 | 选择短时延路线，验证长音频分段和时间轴 |
| 多人对话 | 检查说话人分段、时间戳和重叠说话的表现 |
| 多路对照 | 保存每个引擎的独立输出，比较后再选择或整理 |
| 在线处理 | 先核对授权、传输条件、费用和凭据状态 |

预设描述用途、候选引擎和所需配置。执行前将预设解析为明确的运行计划，并记录本次选择。硬件变化、缓存目录迁移或服务商权限变化后重新核对。 [推荐和可移植配置](asr-production-recommendation-portability.md)

## 任务与产物

1. 导入原音频并记录不可变来源。按任务需要产生规范化音频、分段和时间戳，保留与原时间轴的对应关系。
2. 每个引擎保存各自的原始输出与标准化结果。一条路线失败时，其他成功产物仍然可查。
3. 人工对照记录、融合文本和发布稿各自保留。再次整理已有结果读取原运行产物。
4. 保存任务标识、阶段、来源和产物清单。界面、CLI 和适配器通过原任务标识指向同一份结果。
5. 预处理缓存与临时文件可以重建；清理前确认关联任务状态和需要保留的输出。

分段、降噪和说话人检测按任务选择。记录参数能帮助复现和比较，敏感源音频与内容留在任务工作区。 [ASR 验收](specs/asr-control-plane/acceptance.md)

## 历史测试机与一条性能参照

| 项目 | 测试条件 |
| --- | --- |
| CPU | Intel Core i5-12500H，12 核 16 线程 |
| 内存 | 16 GB |
| GPU | NVIDIA GeForce RTX 3050 Ti Laptop，4 GB 显存 |
| CPU 推理 | 一段约 65 分钟的中文音频，INT8 转写约 23 分钟，约为实时速度的 2.8 倍 |

这是一条历史测试记录。推理使用 CPU，显卡规格用来说明机器配置。音频质量、分段、模型、线程与系统负载都会影响结果。规划部署时，用合成音频在目标机器复测壁钟耗时、结果完整性和失败处理。

# 任务中断后的核对与继续

桌面、CLI 和微信复用原引擎的 `progress.blocked/next`、`resumable` 和任务编号。提示说明中断、模型明确拒绝、模型受理未知、预算暂停及当前续接限制；它本身不会启动模型、恢复任务或重新生成结果。

桌面在任务和只读讨论回复下显示恢复说明。**核对原任务**只读取并刷新原记录，读取期间可以继续写草稿，切换后迟到结果不会切回旧会话。它不表示所有外部业务任务已经核对完毕：已有 `jobs` 仍按原编号及已注册的状态/结果接口查询，不调用原生成命令。

核对成功后，恢复卡片会显示原步骤清单，或说明原记录没有保存步骤。展开单步时才读取正文，按原会话、轮次和步骤编号核对归属。部分后台结果还没查到时保留对应提示。模型结果仍未知时，继续按钮不出现。微信查询已停轮次时会同时说明仍未知的模型结果，以及能从原记录核对到的完成部分。桌面核对反馈放在原卡片的状态区域，展开结果由用户控制。 [W3C 状态消息](https://www.w3.org/WAI/WCAG22/Techniques/aria/ARIA22)

**继续原任务**需要后端 `resumable=true` 且当前默认模型已启用。点击时提交原任务编号和显示时的 `resume_generation`，沿用原模型快照、检查点及已保存结果。模型关闭时仍可以读取原记录。回执丢失会刷新原任务。旧版本的继续请求只返回原任务现状，后来再次暂停时可在确认新版状态后明确继续。

`resumable` 只说明当前记录满足结构条件，不是授权、模型可用性、费用或成功保证。后端执行入口会重新检查当前模型开关、运行时兼容、累计上限、同会话其他工作及全局四个执行名额；原执行器仍在收尾时不误改为运行中。打开页面和读取提示不构成执行同意。后续聊天已经结束时，可以继续满足条件的较早任务：仅移除能唯一归属原任务的旧上下文组，保留后续对话、原编号、原检查点及已完成效果，不再直接弹出最后一组历史。尚未开始的后续队列不阻止原任务继续，也不因此自动解锁；另有正在处理或等待确认的轮次时仍拒绝。微信短“继续”和“继续排队”的准确选目标规则见[队列续接](assistant-queue-resume.md)。

旧上下文没有独立归属字段。若原组已经不在有界窗口、存在重复组、其他轮次有相同提交组，或者原输入缺失，当前无法唯一确认归属，明确拒绝续接并保留全部历史。没有提交历史的中断不移除任何组。这没有扩大历史容量，也不迁移原记录。代码与隔离证据见后续聊天续接计划和验收记录；日常程序是否支持须现场查询，不从本说明推断已更新。

| 情况 | 下一步 |
| --- | --- |
| 模型服务明确拒绝/连接未送达 | 保留已完成步骤；满足原任务续接条件时可明确继续，仍须核对实际返回。 |
| 模型是否受理未知 | 保留原请求，先查已受理业务和已有结果，不重复推理。 |
| 业务结果未知 | 先按原业务编号查状态/结果；图恢复仍经过原失败屏障，不能借“继续”重做未知动作。 |
| 没有检查点/版本不兼容/到累计上限/存在其他活动任务/历史归属不明 | 原任务保持可查；不提供直接继续入口，不用新任务掩盖旧结果。 |

外部 AI 先运行 `hb describe assistant_turn_get`，用原 `turnId` 读取当前任务。需要业务结果时按返回 jobs 的原编号和已注册查询接口继续，参数以 describe 为准。明确继续时，给 `assistant_resume` 传原 `turnId` 和刚读取的 `expectedGeneration`，值取自原 `resume_generation`。重试保留这两个值及原控制请求编号。重复的旧版本请求返回原状，不追加续接预算或重新核对业务回执。只有旧客户端兼容路径可省略该字段。之后按原 `turn_id` 查询完成、结果和产物。微信的“进度/结果”及明确“继续”沿用同一个来源绑定任务。

本轮没有新增命令或改变持久化格式。实际验收和仍未完成的原生窗口/部署事项见验证记录。

续接请求复用了任务已有的持久版本号。设计参考了条件请求把写操作绑定到读到的版本这一原则，以及 LangGraph 用检查点恢复原线程状态的机制。旧版本续接按 HomeBase 原任务回执返回现状。 [RFC 9110 条件请求](https://www.rfc-editor.org/rfc/rfc9110.html#section-13.1.1) · [LangGraph 持久化](https://docs.langchain.com/oss/python/langgraph/persistence)

设计依据：实际读取 [LangGraph interrupt 固定源码](https://github.com/langchain-ai/langgraph/blob/02f2c2e6c992ffccce9e9129781fdd04f015c6fa/libs/langgraph/langgraph/types.py)，核对恢复依赖检查点、按任务和中断顺序匹配，节点恢复可能重新进入节点逻辑。还核对本项目锁定的 `@langchain/langgraph` 1.7.3 已安装 `dist/interrupt.js`：使用当前任务 scratchpad/namespace 并保留已回答序列。HomeBase 保留原请求身份和副作用账本，在应用层区分只读核对与明确续接；不把 SDK 恢复当作自动具备业务幂等性。没有升级运行库、复制框架实现或迁移旧检查点。

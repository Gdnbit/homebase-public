# 助理最近任务发现与结果查询

适用范围：HomeBase内置助理及复用同一Engine的微信通道。CLI公开任务账本及原生Agent自身任务保持原契约；本文件不增加执行或授权接口。

`homebase_jobs`读取最近控制任务元数据，最多返回12条。它是近期列表，不是全量历史，也不读取私人结果。列表作为本会话的工具步骤保存一次；不把发现的job登记为本会话提交，不为每一行反复保存整个加密状态，不占用自有任务执行名额。

`homebase_job(job_id)`接受两类编号：本会话原登记任务，以及本会话已完成的`homebase_jobs`工具步骤确实返回的编号。模型参数、普通文字、其他工具的同名字段、失败/预览步骤及其他会话的发现不能代替证据。重启后从原工具步骤查找，无需重跑列表或原业务。

自有job沿用原进度、远端跟进、结果和文件登记逻辑。非自有job只查询原控制job，按原命令策略核对私人结果确认；即使曾看过元数据也不能跳过确认。查询响应核对原job_id/command，返回`query_only:true/owned:false`，不创建业务job、远端轮询任务或附件投递。它不能用于`homebase_deliver`、仓库/视频产物归属或Skill工作区授权。旧非自有记录兼容且保留，不自动升级所有权。

控制成功但结果已回收/重启不可读时，明确返回`JOB_RESULT_UNAVAILABLE`与未知结果，而不是把null当成业务成功。业务仍在运行、失败、取消、超时或未知也保留实际状态；查询失败不重新提交。重复微信原消息仍由原回执去重，不会再次推理或重做操作。

## 容量边界

当前仍有自有任务100条、会话消息200条、会话100条及总状态24MiB的保护边界。历史非自有元数据不再消耗自有名额；本次修复不是无限历史或完整归档。已有任务/消息不删除，达到自有容量后仍需明确处理，后续归档必须保留原编号、权限、结果、重复执行屏障和在途恢复。

本阶段方案与验证要求。验证使用隔离控制器、脚本模型和自动模拟微信；不能据此宣称真实免费模型或真实手机投递通过。

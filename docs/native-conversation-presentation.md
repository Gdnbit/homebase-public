# 原生会话展示与交接

这层只整理展示，不修改SDK历史、回执、工具绑定、密钥或原任务。模型仍收到原适配器组织的输入；UI不会按某个文本前缀把内容删除，也不把资料推断成系统指令。

## 消息和标题

原生用户消息可能含多个文本块。首块/主文本在聊天中展示，其余文本以“附带原生输入”可展开查看，原文完整保留。这些块可能来自用户或SDK背景，来源不明时明确不作语义认证；字面包含AGENTS或environment标签的用户正文照常显示。助手的多个文本段直接连续展示。非文本内容明确提示尚不预览，不伪装已经识别图片；无文字或格式不可确认也有提示。

实际Codex app-server历史接口会合并原输入块。适配器只在读取历史时，核验SDK给出的路径仍位于当前Codex的sessions根下、原日志session_meta身份相同，并匹配原块拼接与SDK文字的字节摘要后，额外返回 `homebase_input_blocks`；SDK的原content不改。日志最多8MiB、映射最多256个不同输入；相同拼接有不同拆分时拒绝猜测。文件过大、缺失、损坏、越界或格式不匹配时保持SDK原文展示，不按前缀切分。前端再次校验拼接一致，实时事件只有原文字节一致才能复用已核对的分块。此映射不参与授权或模型输入，不产生新的持久化记录。

Codex会话列表标题在一次既有扫描中匹配SDK user_message事件和response_item的输入块拼接摘要，取匹配输入首块的首个非空行，最多120个Unicode码点。事件前后顺序都支持，匹配候选有界。事件无法匹配时不把环境前置消息冒充用户标题；无事件的旧日志保守选择非前置输入预览。原始记录、计数和历史详情不因预览而删改。这不是对所有未来SDK格式的永久保证，无法确认时保持未命名。

消息到来时，正在末尾的读者跟随最新内容；向上阅读时保持位置，提供查看新消息入口。只有可见消息文字变化才提示新消息，状态变化不冒充新回复。加载更早历史前按当前滚动位置保存锚点，包含等待期间用户继续滚动的情形；补读后保持原位置。

## HomeBase共享关联

Codex read同时只读查询其已有ledger关联，返回assistant_session_id及context_link_state：linked、not_linked或unavailable。缺少绑定不等于自动拥有HomeBase工具；关联读取失败返回partial和说明，但保留可读SDK历史。不会新建/改绑、续接或执行。Claude/Gemini继续使用其原Record中的关联。

会话刷新核对相应历史/状态/列表；ACK与当前读取复用既有查询，避免无意义反复扫描。共享任务入口来自实际关联，不由客户端猜测。工作目录在账号与权限详情中按需展开，主要聊天不被长路径占据。

## 显式交接

交接只准备新HomeBase会话草稿，不发送、不停旧任务、不迁移原生身份。复用当前已读取的原生历史查询，保留已加载的分页；取消携带文字不另读历史。读取失败时须修复或取消携带，不能用空摘要假装成功。

携带内容是JSON引用资料，最多最近8条文字摘录，每条有界并标明是否截取；预算优先保留较新的信息。主文本和附带文本均可进入摘录，非文本资料不自动迁移。partial/total_selected及truncated明确这不是无损续接，原记录始终保留。整个草稿按UTF-8不超过8000字节，保留完整新目标，不能截坏emoji；新目标无法容纳时在新建会话前报错，不制造空会话。用户还可取消携带，只准备新目标。

实际版本与隔离验收见持续Goal。这些是客户端与来源展示规则，不是新的任务引擎或额外授权。

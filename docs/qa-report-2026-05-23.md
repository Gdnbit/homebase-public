# HomeBase 桌面 QA 回顾

这份记录提炼自 2026 年 5 月的桌面 QA。它记录问题与复验思路，当前页面布局和接口以主分支为准。

| 当时的问题 | 可复用的验收方式 |
| --- | --- |
| Agent 对话抽屉出现过时的阶段名称 | 分别打开有历史、无历史和读取失败的合成会话，标题及状态应对应实际结果 |
| 资料处理页出现旧占位提示 | 以明确的加载、空、错误和可操作状态覆盖未就绪页面 |
| 创作空态展示内部代号 | 用用户能理解的下一步替换工程阶段名称 |
| System 的 PATH 和进程只显示占位 | 用可失败的查询显示系统事实，区分未知、访问失败和空结果 |
| Windows 手工配置文件带 UTF-8 BOM 时解析失败 | 用有 BOM 和无 BOM 的合成 JSON、TOML 文件覆盖读取结果 |

## 可重复检查

在测试目录创建最小合成配置，切换页面、手动刷新，再模拟读取异常和恢复。核对组件是否访问当前来源，是否将单个查询失败误报为空。记录平台、相关入口、出现条件与修复后的结果。

Windows 上手工编辑的 UTF-8 文本可能带 BOM。适配器应在解析时处理文本前缀，测试覆盖新旧输入，保存路径保持其既有编码约定。历史回归中使用的真实应用列表和进程信息留在本机。

当前的重跑入口见 [隔离验证地图](verification-map.md) · [页面性能](page-performance.md)。

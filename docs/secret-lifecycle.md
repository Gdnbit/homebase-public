# 密钥保存、轮换和到期机制

本说明对应 2026-11-08 的本地实现。密钥仍由 SOPS 加密保存，生命周期元数据保存在同目录的 `secrets-meta.json`。本次开发和验收没有读取或写入用户的真实密钥库，也没有申请、撤销或测试真实服务商凭据。

## 状态与保存

- 密钥使用自适应卡片网格展示，沿用全局卡片样式；卡片展示服务、已填状态及到期策略。点击卡片在弹窗中编辑，背景网格不改变布局；调整窗口大小不会重建编辑器或丢弃草稿。弹窗支持 Esc、关闭按钮和点击遮罩关闭；有未保存草稿时需确认，写入进行中不能关闭。
- 列表明确区分缺失、空白、非字符串异常值和已填；已填表示有值，不表示服务商验证有效。
- 展开编辑后，名称、到期日期、服务配置、轮换链接和到期策略停止输入 800ms 后自动保存。失败时展示错误并保留草稿。
- 密钥正文只在内存草稿中保留，必须点击加密保存或轮换；不会作为明文自动保存到磁盘、浏览器存储或 React Query 缓存。
- 标题栏关闭和侧栏「退出 HomeBase」共用密钥编辑保护。新增或编辑仍有未保存内容时，会询问是否放弃，返回后保留原输入。密钥写入等待回执时保留窗口，完成后可再次退出。关闭流程只读取草稿和写入状态，密钥正文继续留在编辑器内。退出请求发出后，尚未开始的密钥保存暂停。首次退出明确失败后，恢复编辑及元数据自动保存。
- 新增密钥及其元数据使用一次版本化请求。已有值必须走轮换，不允许普通保存静默覆盖。
- 密钥经 stdin 交给 SOPS，不进入进程参数。暂存文件先加密写入，解密后逐字节比较，验证通过才提交。
- 显示当前明文需主动操作，30 秒后隐藏，失焦、隐藏页面或关闭编辑时立即隐藏。JavaScript 字符串受垃圾回收管理，不能承诺物理内存立即覆写。

## 事务与恢复

以操作系统文件锁串行化整个读改写过程；每次请求校验行版本和加密库、元数据的整体版本。冲突后保留草稿，读取服务器状态并明确核对后重试，不自动覆盖其他写入。

提交前创建纳秒时间戳加 UUID 的唯一备份，保存加密 YAML 和原元数据。备份解密沿用原密钥库旁的身份文件查找位置，不把 `backup` 当成新的身份根目录。事务日志只包含加密 YAML 与非密钥元数据的前后映像，不存储密钥明文。两份文件分别原子替换；Windows 保留原文件 ACL。提交失败尝试恢复原文件；进程中断后的下次刷新在锁内恢复已准备事务。在日志未清理前，消费者拒绝提供凭据。

元数据损坏不会用空表覆盖；无法恢复、权限失败或发现未知外部修改时停止操作，保留日志及备份供核对。旧备份不自动删除。直接使用外部编辑器或 SOPS 的进程不遵守 HomeBase 的锁，存在最终检查与替换之间的竞态窗口；写入时应关闭这些工具。此机制不承诺跨非协作写入者的分布式事务，也不承诺断电后的硬件级持久化。

## 轮换流程

1. 在服务商创建新密钥，填写候选值及新到期日期；日期留空明确表示未记录，不继承旧到期时间。
2. 主动检测候选值，或在服务商处人工确认。没有受支持接口的服务明确显示需要人工验证。检测结果只代表本次接口和权限范围。
3. 勾选新密钥可用、旧密钥尚未撤销的确认，再切换。保存和逐字节校验通过后记录轮换。
4. 验证下游使用后，到服务商停用旧密钥，再在 HomeBase 确认。该按钮只记录人工确认，不调用撤销 API。
5. 旧密钥尚未确认停用时，可明确确认后撤回切换。仅恢复这把密钥及其原到期策略，其他密钥不变。确认旧密钥停用后禁止回退；未结束的轮换禁止再次轮换。

服务配置用于检测与服务商链接；自定义短名不会自动建立 Agent/MCP 绑定。不会自动创建或撤销服务商密钥，也不会将已注入外部进程的旧环境变量自动替换；需要重启相关消费者。

## 到期策略与提醒

- 选择日期按本机时区当天 23:59:59.999 保存为含时区时间。恰好七天进入提醒，到达时间点视为到期；无效日期显示告警，无日期显示未记录。
- 默认 `warn` 只提醒，保留旧条目行为；用户主动选择 `block` 后，过期或无效日期会阻止 HomeBase 适配层和新编译的 reveal helper 提供该密钥。日期未记录无法推断过期。不会在服务商撤销凭据，也不能追回已交给外部进程的明文。
- 列表和首页每 30 秒更新时间；全局到期检查每分钟读取元数据，恢复前台时刷新。检查失败明确显示未知，不能当成没有告警。
- 全局提醒位于侧栏「密钥」旁的铃铛：到期或轮换待办显示红点，读取失败显示黄点和状态未知；不再占用页面顶部。点击铃铛才展开详情与手动刷新、系统提醒开关，点击外部或按 Esc 收起。收起不会清除待办或修改密钥状态；页面切换不会重复创建检查器。
- 系统提醒需用户主动启用，按日期和告警集合去重。应用关闭后没有后台定时任务。本实现不会从服务商自动同步到期时间。

支持的检测地址是代码内固定的只读 GET 接口，不允许用户自定义带凭据请求地址，且不跟随重定向。OpenRouter、Firecrawl、Tavily 本次按官方接口调整：

- [OpenRouter 当前密钥](https://openrouter.ai/docs/api_reference/limits)
- [Firecrawl credit usage](https://docs.firecrawl.dev/api-reference/endpoint/credit-usage)
- [Tavily usage](https://docs.tavily.com/documentation/api-reference/endpoint/usage)

未确认存在只读认证接口的服务保持人工验证。GDNbit 不再用发布预览请求测试凭据。

## 路径及兼容

统一优先使用非空 `HOMEBASE_SECRETS_FILE`，其次 `HOMEBASE_SECRETS_YAML`，默认 `C:\HomeBase\Secrets\secrets.yaml`；`HOMEBASE_SECRETS_META` 可覆盖关联元数据路径。适配层和 helper 共享解析与到期策略。

需要支持 `sops set --value-stdin` 的 SOPS（隔离验收使用项目自带 3.12 系列）。不加密后缀、正则排除范围或无法安全判断的注释加密规则禁止自动写入。旧 `secrets_set`、`secrets_set_meta` 命令拒绝非版本化写入，提示刷新到新客户端。

## 隔离验收入口

```powershell
npm run test:secrets
npm run test:secrets:native
npm run test:secrets:ui
```

原生测试使用独立 Cargo harness 编译实际生产模块和 reveal helper，排除可能读取真实库的旧测试。每个夹具建立临时目录、全新 age 身份、明确的 SOPS 配置和合成凭据；子进程清空继承环境，只保留运行所需系统项并把用户目录指向临时目录，网络代理指向不可用的本地地址。HTTP 检测使用本机模拟服务。浏览器使用独立 Edge 测试上下文与模拟 IPC，禁止外网请求，不连接真实 Tauri。

结果与交付边界见 隔离验收记录。不要运行全量原生测试来替代以上隔离入口，旧 SOPS 测试可能访问真实密钥库。
